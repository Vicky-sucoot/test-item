# 原卷提供格式（PDF／網址清單）

之後逐批提供官方原卷時，請用下列格式整理。範本檔：`public/templates/source-manifest-template.csv`（管理頁「匯入」也可下載）。

## 1. 原卷清單（CSV，一列一份試卷）

| 欄位 | 必填 | 說明 |
|---|---|---|
| batch | ✔ | 批次編號（1、2、3…），方便逐批核對 |
| source_type | ✔ | `BANK_EXAM` 銀行甄試題／`FIT_REFERENCE` FIT 參考試題 |
| bank | 甄試題必填 | 第一銀行、合作金庫、臺灣銀行、臺灣土地銀行、華南銀行、兆豐銀行、彰化銀行、臺灣中小企業銀行 |
| year | ✔ | 民國年度（105～114） |
| exam_name | ✔ | 依官方公告的甄試名稱，例如「○○年度新進人員甄試」 |
| position |  | 職缺／類別（同一次甄試不同職缺試卷不同時必填） |
| paper_subject | ✔ | 原卷科目名稱，照原卷寫（例：綜合科目、會計學） |
| exam_date |  | 考試日期 YYYY-MM-DD |
| paper_file | 二擇一 | 你提供的試題 PDF 檔名 |
| paper_url | 二擇一 | 官方試題網址（建議兩者都提供） |
| answer_file |  | 官方答案 PDF 檔名 |
| answer_url |  | 官方答案網址 |
| announcement_url |  | 甄試公告頁網址 |
| answer_corrections |  | 是否有更正答案（送分、一題多答）公告；有的話附網址 |
| note |  | 其他說明（例如：掃描檔、缺頁） |

## 2. 檔案命名建議

```
{年度}-{銀行}-{甄試名稱簡稱}-{科目}-試題.pdf
{年度}-{銀行}-{甄試名稱簡稱}-{科目}-答案.pdf
例：113-臺灣銀行-新進人員-綜合科目-試題.pdf
```

## 3. 注意事項

- 只提供官方來源（銀行官網、台灣金融研訓院公告）。第三方題庫不作為來源。
- 掃描影像 PDF 第一階段無法擷取文字，請在 note 註明；之後可改用 CSV 手動輸入，或等第二階段 OCR。
- 若官方未公布答案，answer_file／answer_url 留空，系統會標示「缺少官方答案」，不推測。
- 票據法、銀行法題目請盡量提供考試日期，以便判定「考試當時適用法規」。

## 4. 匯入步驟

1. 管理 → 匯入 → PDF 匯入：填入清單上的試卷資料，上傳試題 PDF（與答案 PDF）。
2. 在「匯入檢查」頁逐題對照原卷：修正題幹／選項／答案、指定科目與主題（綜合科目會先給系統建議，無法判斷者為「待人工分類」）。
3. 勾選「已與原卷（及官方答案）逐字核對」並儲存。
4. 按「發布已核對的 N 題」，題目才會進入本機題庫。
