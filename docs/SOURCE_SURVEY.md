# 歷屆考題官方來源調查（第一輪，2026-11-17）

範圍：第一銀行、合作金庫、臺灣銀行、臺灣土地銀行、華南銀行、兆豐銀行、彰化銀行、臺灣中小企業銀行；民國 105～114 年（暫定）。
實際收錄以取得並核對的原卷與答案為準，**本文件不含任何試題內容**。

## 1. 結論

- 八家銀行近年的新進人員甄試，試務多由**財團法人台灣金融研訓院（TABF）**受託辦理。
- 簡章載明：考後約 1 個工作天，「試題與選擇題解答」於該次考試的**甄試專區**公告。例如：
  - 彰化銀行 113 年簡章：「試題及選擇題答案於 113 年 5 月 13 日起於甄試專區公告」
  - 兆豐銀行 114 年專區公告：「第一試試題與選擇題解答查詢 [2025/05/19]」
- 甄試專區網址規則：
  - 110 年起：`https://svc.tabf.org.tw/{民國年}{銀行代碼}{期次}/`
  - 105～109 年：舊網域 `https://ptc.tabf.org.tw/tw/ptc_{年月或年}{銀行代碼}/`
- 銀行代碼：

  | 銀行 | 代碼 |
  |---|---|
  | 第一銀行 | `firstbank` |
  | 合作金庫 | `tcbbank` |
  | 臺灣銀行 | `bot` |
  | 臺灣土地銀行 | `landbank` |
  | 華南銀行 | `hncb` |
  | 兆豐銀行 | `megabank` |
  | 彰化銀行 | `chb` |
  | 臺灣中小企業銀行 | `tbb` |

- TABF 網站另有「歷屆試題」檔案路徑（`/_File/Download/{專區代碼}/HistoryPaper/…pdf`），已看到其他機構使用此路徑；八家銀行是否也有，尚未確認。

## 3. 這一輪無法完成的部分

- 雲端工作環境的網路已加入 TABF 三個網域，但讀取專區頁面時被安全檢查拒絕。因此**沒有實際開啟任何專區**，以下都無法確認：
  - 專區目前是否仍保留試題與解答
  - 檔案網址
  - 網站的著作權或使用聲明
- 第三方考古題網站（3people、public.com.tw、347.com.tw、PressPlay 等）的檔案**一律未採用**。

## 4. 下一步

1. 你用瀏覽器開啟 `source-manifest.csv` 的專區網址，確認有沒有「試題與選擇題解答」與「歷屆試題」，再下載 PDF。
2. 在本機完整版的管理頁 →「匯入」上傳 PDF 與答案 PDF，逐題核對後發布。
3. 把確認後的檔案網址、狀態填回 `source-manifest.csv`（paper_url、answer_url、paper_status、answer_status），並在管理頁「來源與試卷」記錄使用條件。
4. 105～109 年舊網域（`ptc.tabf.org.tw`）的檔案可能已下架。若找不到，可向 TABF（02-3365-3666）或各銀行人資單位詢問。
