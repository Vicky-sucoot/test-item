# 公股銀行考題練習（本機版）

會計學、貨幣銀行學、票據法、銀行法分科練習網頁。繁體中文介面，手機與電腦皆可使用。
目前已完成**第一至三階段**（第二階段：限時模擬考；第三階段：依真實考試各科比例出題）。題庫僅含**自編示範題**（非歷屆真題，答案為自編參考答案，非官方答案），供你個人在本機使用。

- 規劃書：[docs/PLAN.md](docs/PLAN.md)
- 原卷提供格式：[docs/SOURCE_FORMAT.md](docs/SOURCE_FORMAT.md)

## 環境需求

- Node.js 20.9 以上（建議 22 LTS）
- npm

## 啟動

```bash
npm install
```

```bash
cp .env.example .env.local
```

編輯 `.env.local`，把 `ADMIN_PASSWORD` 改成你自己的管理密碼。

```bash
npm run dev
```

開啟 <http://localhost:3000>。第一次啟動會自動建立 `data/app.db`，並載入預設主題章節、來源檢查表，以及 21 題自編示範題（四科各 5 題，另 1 題刻意不給答案，用來展示「缺少官方答案」）；其中 2 題重複收錄在第二份示範題組，用來展示重複標記，所以題庫共 23 筆。

## 手機使用本機完整版（網址／QR code／安裝 App）

1. 手機與電腦連上同一個 Wi‑Fi。
2. 在電腦執行：

   ```bash
   npm run lan
   ```

   會先建置，再以正式模式啟動。終端機會印出手機網址（例如 `http://192.168.1.23:3000`）和 **QR code**，用手機相機掃描即可開啟。
3. 網站開著時，電腦瀏覽器開啟 <http://localhost:3000/connect>（上方選單「手機／App」）也會顯示 QR code 與安裝說明；也可以輸入其他網址產生 QR code。
4. 安裝成 App（PWA）：
   - iPhone：Safari「分享」→「加入主畫面」。
   - Android：Chrome「⋮」→「加到主畫面」。
   - 電腦：Chrome／Edge 網址列的「安裝」圖示，或「手機／App」頁的「安裝 App」按鈕。

說明：
- 題庫與作答紀錄存在電腦上，所以手機使用時，電腦要開著並執行網站。連不到時，會顯示離線提示頁（https 或 localhost 環境）。
- 透過區網 http 網址連線時，Android 只能建立主畫面捷徑。iPhone 加入主畫面後會以全螢幕開啟。
- `npm run lan` 執行期間，同一網路的其他裝置也能開啟網站：練習頁不需密碼，管理頁需要密碼。請只在信任的網路使用。
- 開發用的 `npm run lan:dev` 也能讓手機連線，但頁面互動依賴開發伺服器的即時連線，手機使用請以 `npm run lan` 為主。
- 本系統沒有部署到公開網路，所以沒有固定的公開網址。若要在外面使用，需要另外設定 HTTPS 通道或主機，並先確認真題的使用條件。

| `npm run dev` | 開發模式啟動（僅本機） |

資料都存在 `data/app.db`（不會提交到 git）。要備份，請在伺服器停止時複製這個檔案。

## 驗收步驟（第一階段）

1. **分科刷題**：首頁點「會計學 → 隨機練習 10 題」，逐題作答後按「交卷」。結果頁應顯示正確率、各科正確率、每題答案、解析（標示「解析待審核」）、來源資訊。「示範・缺少答案」那題應顯示「缺少官方答案（不推測、不判分）」，且不計入正確率。
2. **篩選**：題庫頁依來源類型、科目、主題、銀行、年度、甄試名稱、關鍵字篩選。選「貨幣銀行學」為 6 題，勾選「合併重複題」後為 5 題。
3. **即時回饋**：題庫頁勾選「每題作答後立即看答案」再開始練習，作答後立刻顯示對錯與解析，且該題不能再改。
4. **錯題複習**：答錯的題目出現在「錯題・收藏 → 待複習錯題」。在複習中連續答對 2 次後，移到「已熟悉」分頁；作答紀錄保留，可按「繼續複習已熟悉題目」或「移回待複習」。
5. **收藏**：在練習、結果頁或題目頁按「☆ 收藏」，「收藏」分頁應出現該題。
6. **統計**：「統計」頁顯示各科與各主題正確率、近日作答、作答紀錄（可點進看結果，未交卷的可繼續作答）。
7. **重複題與法規**：開啟 `/q/12?show=1`（票據法示範題），應看到「重複題：此題亦出現於 自編示範題組 B 第 2 題」，以及法規資訊：「考試當時適用法規」「需重新核對目前法規」「尚未建立法條引用（條文未核對）」。
8. **管理登入**：點「管理」，輸入 `.env.local` 的密碼。
9. **CSV 匯入**：管理 → 匯入 → 下載題目 CSV 範本 → 上傳。檢查頁會顯示警示（例如「科目待人工分類」「缺少官方答案」）。勾選第 1 筆「已與原卷核對」→ 儲存 → 「發布已核對的 1 題」。未核對的題目不會發布。
10. **PDF 匯入**：用任何文字型 PDF 試題（格式如 `1. 題幹 (A)… (B)… (C)… (D)…`）上傳，可同時上傳答案 PDF 或貼上答案文字。檢查頁可對照「PDF 擷取原文」，逐題修正、分類、核對後發布。
11. **題目管理**：修改題目、答案、解析審核狀態、資料核對狀態、法規欄位；新增法條引用（法規名稱、條號、核對日期、核對來源）；標記或解除重複題；下架題目。
12. **主題章節**：在「主題章節」修改名稱、排序，或新增、刪除主題。
13. **來源與試卷**：記錄各銀行與台灣金融研訓院的使用條件檢查結果；修改試卷的原卷網址、答案網址等資料。

### 第二階段：限時模擬考

14. **預設模擬考**：點上方「模擬考」，有兩種：
    - 會計學＋貨幣銀行學：80 題、90 分鐘
    - 票據法＋銀行法：50 題、60 分鐘
    兩科平均出題，某科題目不足時由另一科補足；題庫題目不足時，卡片會提示「本次將以 N 題進行」（目前示範題各 10 題）。
15. **計時**：作答頁右上與底部都有倒數計時，剩不到 5 分鐘變紅色；作答中不顯示答案。重新整理或關閉後再開，時間會繼續倒數（以伺服器時間為準）。
16. **自動交卷**：時間到會自動交卷；若當時沒開著頁面，下次打開該場考試、模擬考頁或統計頁時，系統會自動以「時間到」交卷。截止 5 秒後送出的作答會被拒絕。
17. **成績**：結果頁顯示分數（依計分題數換算為 100 分）、手動交卷或時間到、用時／時限、各科正確率。未作答的題目計為答錯，但不加入錯題本；答錯的題目加入錯題本。
18. **出題範圍**：可選來源類型（銀行甄試／FIT／示範題）；預設排除缺少官方答案的題目，同一重複群組只出一題。
19. **自訂模擬考**：在「自訂模擬考」選科目、題數、時間。
20. **紀錄**：模擬考頁下方列出歷次成績、用時，進行中的考試可以繼續作答。

### 第三階段：依真實考試各科比例出題

系統**不內建、也不推測**任何銀行的各科題數比例。比例只來自你匯入並核對過的真題，或你手動輸入的數字。

21. **預設為自動統計**：統計對象是已發布、且勾選「已與原卷核對」的**銀行甄試題**（FIT 參考試題與示範題不列入）。依各科題數算出比例，再用最大餘數法換算成 80 題或 50 題。目前只有示範題，所以模擬考頁會顯示「尚無…已核對的銀行甄試真題，暫以平均分配」。
22. **模擬考卡片**：顯示比例來源，以及每科的比例、預計題數、題庫可出題數、本次實際題數。某科題目不足時，差額依比例由其他科補足。
23. **管理 → 模擬考比例**：每種考試可以選「依已核對真題自動統計」「手動設定比例」或「平均分配」。
    - 自動統計可以限定銀行、起訖年度，下方列出每份試卷各科題數，方便你核對。
    - 手動比例可以直接填題數（例如 20、30）或百分比。
24. **驗收方式**：在管理頁把「票據法＋銀行法」設為手動 20：30，模擬考卡片應顯示 40%／60%、預計 20／30 題；開考交卷後，結果頁顯示「出題比例：手動設定…、預計／實際題數」。之後匯入並核對真題，選「自動統計」後比例會依真題改變。
25. **自訂模擬考**：可選「依已核對真題統計」或「平均分配」。

## 資料規則

- 來源類型分三種，永遠分開標示：銀行甄試題、FIT 參考試題（非銀行甄試題）、自編示範題（非歷屆真題）。
- 沒有官方答案時，答案狀態為「缺少官方答案」：不推測、不判分、不加入錯題本。示範題不能標為官方答案；真題不能使用自編答案。
- 同一題出現在不同試卷時，各自保留來源、題號與答案，並以「重複群組」連結。
- 票據法、銀行法題目顯示「考試當時適用法規」「目前法規是否需重新核對」，法條引用必須有法規名稱與條號；沒有核對日期的引用顯示「條文未核對」。
- 解析新增或修改後為「待審核」，要由你在題目管理頁勾選審核，才會變成「已審核」。
- 匯入的題目必須逐筆勾選「已與原卷核對」才能發布。
