# 公股銀行考題練習（本機版）

會計學、貨幣銀行學、票據法、銀行法分科練習網頁。繁體中文介面，手機與電腦皆可使用。
目前為**第一階段**：題庫僅含**自編示範題**（非歷屆真題，答案為自編參考答案，非官方答案），供你個人在本機使用。

- 規劃書：[docs/PLAN.md](docs/PLAN.md)
- 原卷提供格式：[docs/SOURCE_FORMAT.md](docs/SOURCE_FORMAT.md)

## 環境需求

- Node.js 20.9 以上（建議 22 LTS）
- npm

## 啟動

```bash
npm install
```

```bash
cp .env.example .env.local
```

編輯 `.env.local`，把 `ADMIN_PASSWORD` 改成你自己的管理密碼。

```bash
npm run dev
```

開啟 <http://localhost:3000>。第一次啟動會自動建立 `data/app.db`，並載入預設主題章節、來源檢查表，以及 21 題自編示範題（四科各 5 題，另 1 題刻意不給答案，用來展示「缺少官方答案」）；其中 2 題重複收錄在第二份示範題組，用來展示重複標記，所以題庫共 23 筆。

手機測試：電腦與手機在同一個 Wi‑Fi 時，用 `npm run dev -- -H 0.0.0.0` 啟動，再以手機瀏覽 `http://電腦IP:3000`。

## 常用指令

| 指令 | 用途 |
|---|---|
| `npm run dev` | 開發模式啟動 |
| `npm run build && npm run start` | 正式模式啟動 |
| `npm test` | 執行單元與資料庫流程測試 |
| `npm run typecheck` | TypeScript 型別檢查 |
| `npm run db:reset` | 刪除本機資料庫（含作答紀錄與匯入資料），下次啟動重建示範資料 |

資料都存在 `data/app.db`（不會提交到 git）。要備份，請在伺服器停止時複製這個檔案。

## 驗收步驟（第一階段）

1. **分科刷題**：首頁點「會計學 → 隨機練習 10 題」，逐題作答後按「交卷」。結果頁應顯示正確率、各科正確率、每題答案、解析（標示「解析待審核」）、來源資訊。「示範・缺少答案」那題應顯示「缺少官方答案（不推測、不判分）」，且不計入正確率。
2. **篩選**：題庫頁依來源類型、科目、主題、銀行、年度、甄試名稱、關鍵字篩選。選「貨幣銀行學」為 6 題，勾選「合併重複題」後為 5 題。
3. **即時回饋**：題庫頁勾選「每題作答後立即看答案」再開始練習，作答後立刻顯示對錯與解析，且該題不能再改。
4. **錯題複習**：答錯的題目出現在「錯題・收藏 → 待複習錯題」。在複習中連續答對 2 次後，移到「已熟悉」分頁；作答紀錄保留，可按「繼續複習已熟悉題目」或「移回待複習」。
5. **收藏**：在練習、結果頁或題目頁按「☆ 收藏」，「收藏」分頁應出現該題。
6. **統計**：「統計」頁顯示各科與各主題正確率、近日作答、作答紀錄（可點進看結果，未交卷的可繼續作答）。
7. **重複題與法規**：開啟 `/q/12?show=1`（票據法示範題），應看到「重複題：此題亦出現於 自編示範題組 B 第 2 題」，以及法規資訊：「考試當時適用法規」「需重新核對目前法規」「尚未建立法條引用（條文未核對）」。
8. **管理登入**：點「管理」，輸入 `.env.local` 的密碼。
9. **CSV 匯入**：管理 → 匯入 → 下載題目 CSV 範本 → 上傳。檢查頁會顯示警示（例如「科目待人工分類」「缺少官方答案」）。勾選第 1 筆「已與原卷核對」→ 儲存 → 「發布已核對的 1 題」。未核對的題目不會發布。
10. **PDF 匯入**：用任何文字型 PDF 試題（格式如 `1. 題幹 (A)… (B)… (C)… (D)…`）上傳，可同時上傳答案 PDF 或貼上答案文字。檢查頁可對照「PDF 擷取原文」，逐題修正、分類、核對後發布。
11. **題目管理**：修改題目、答案、解析審核狀態、資料核對狀態、法規欄位；新增法條引用（法規名稱、條號、核對日期、核對來源）；標記或解除重複題；下架題目。
12. **主題章節**：在「主題章節」修改名稱、排序，或新增、刪除主題。
13. **來源與試卷**：記錄各銀行與台灣金融研訓院的使用條件檢查結果；修改試卷的原卷網址、答案網址等資料。

## 資料規則

- 來源類型分三種，永遠分開標示：銀行甄試題、FIT 參考試題（非銀行甄試題）、自編示範題（非歷屆真題）。
- 沒有官方答案時，答案狀態為「缺少官方答案」：不推測、不判分、不加入錯題本。示範題不能標為官方答案；真題不能使用自編答案。
- 同一題出現在不同試卷時，各自保留來源、題號與答案，並以「重複群組」連結。
- 票據法、銀行法題目顯示「考試當時適用法規」「目前法規是否需重新核對」，法條引用必須有法規名稱與條號；沒有核對日期的引用顯示「條文未核對」。
- 解析新增或修改後為「待審核」，要由你在題目管理頁勾選審核，才會變成「已審核」。
- 匯入的題目必須逐筆勾選「已與原卷核對」才能發布。
